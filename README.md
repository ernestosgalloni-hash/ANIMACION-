# ANIMACION-

Skill para hacer videos animados desde cero (Remotion) y catálogo de recursos reutilizables.

## Estructura

- `skill/` — el skill para hacer videos (SKILL.md y referencias)
- `catalogo/` — personajes, fondos y animaciones reutilizables
  - `catalogo/INDICE.md` — una línea por recurso: nombre, qué es, dónde está
- `videos/` — un proyecto por carpeta (`video-01/`, `video-02/`, …)
